# case-12 — реверс прошивки usb_token

Реверс-инжиниринг прошивки кибер-сейфа на Raspberry Pi RP2040 для трека Positive Technologies на ЛЦТ 2026: получить доступ к скрытому хранилищу и описать уязвимости

> [!NOTE]
> Хранилище открывается 4-значным PIN с энкодера, но зашифровано оно ключом, зашитым в саму прошивку и не зависящим от PIN — поэтому расшифровывается оффлайн прямо из дампа флеша, без устройства и без перебора

## Устройство

Кибер-сейф на RP2040 (bare-metal, Pico SDK + TinyUSB) выставляет флешку наружу как USB Mass Storage. Скрытое хранилище на флеше `0x10100000` (704 КБ) зашифровано самодельной XOR-гаммой в стиле CTR, ключ гаммы — фиксированные константы прошивки (пул `0x100004ec..0x10000538`). Дамп снят через `picotool save -a` из BOOTSEL — на RP2040 нет защиты флеша от считывания

## Дешифровка хранилища

Нужен дамп флеша `backup_full.bin` (2 МБ, снимается `picotool save -a backup_full.bin` из BOOTSEL):

```sh
python3 attack1/decrypt_storage.py backup_full.bin storage_decrypted.img
```

Скрипт накладывает восстановленную гамму на область хранилища и отдаёт расшифрованный образ. Сектор 0 разворачивается в валидный загрузчик FAT12 — том монтируется обычными средствами, внутри лежит приз-матрёшка из 1337 запароленных архивов. Полный разбор и оценки CVSS — в отчётах `attack1/2/3`
