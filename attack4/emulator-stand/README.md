# attack4 — эмуляторный стенд (без железа)

Полностью софтовый стенд перебора/ввода PIN: настоящая прошивка `usb_token` запускается в эмуляторе RP2040 [rp2040js](https://github.com/wokwi/rp2040js), а атакующий Pico заменяется скриптом, который подаёт импульсы на пины энкодера и жмёт кнопку. Ни микро-USB, ни живого сейфа не нужно — стенд доведён до факта разблокировки в эмуляции

Это дополняет физический стенд ([`../pico-encoder-emulator/`](../pico-encoder-emulator/)) и со-симулятор ([`../sim/`](../sim/)): здесь атака идёт против **реального бинаря** прошивки, с её собственным декодером энкодера, таймером и проверкой PIN

## Что доказывает

- прошивка полностью грузится в эмуляторе (boot2 + XIP + рантайм) и **крутится в блокирующем цикле энкодера — USB не поднимается до верного PIN** (`USB gated behind PIN loop: true`)
- ввод `3952` через эмулированный энкодер приводит к записи флага разблокировки `*0x20002ED2 = 1` → **сейф открыт**; неверный код (напр. `3951`) — нет
- калибровка энкодера снята в самом эмуляторе: при 30 мс/фронт декодер считает чисто и монотонно (медленнее — теряет фронты как дребезг). Набор идёт **closed-loop**: крутим, пока индикатор не покажет нужную цифру, — устойчиво к точному числу фронтов на цифру

## Запуск

```
npm install            # тянет rp2040js
./fetch-bootrom.sh     # качает RP2040 bootrom B1 -> bootrom.mjs (BSD-3, не вендорится)
node stand.mjs ../../artifacts/backup_full.bin 3952
node stand.mjs ../../artifacts/backup_full.bin 3951
node oracle_demo.mjs ../../artifacts/backup_full.bin 3951
```

Файл [`artifacts/backup_full.bin`](../../artifacts/backup_full.bin) — сырой дамп флеш-памяти; путь передаётся аргументом и может указывать на другой полный дамп. `stand.mjs` возвращает код 3 для закрытого сейфа, поэтому второй запуск ожидаемо завершается с этим кодом. Протоколы корректного и неверного PIN — в [`demo_output.txt`](demo_output.txt)

## Тайминг-оракул (CWE-208) — [`oracle_demo.mjs`](oracle_demo.mjs)

На 4-м нажатии прошивка вызывает `sleep_ms(50)` по разу на каждую совпавшую ведущую цифру, заморозив все выходы. Скрипт инструментирует вход в `sleep_ms` (`0x1000239c`) и считает вызовы с аргументом ровно 50 (тик опроса использует 2, анимация отказа — 200) — счётчик и есть число совпавших цифр k, а 50·k мс = наблюдаемое "время раздумья". Измерено на настоящей прошивке:

| введённый код | совпавший префикс k | заморозка (think-time) |
|---|---|---|
| 0952 | 0 | 0 мс |
| 3052 | 1 | 50 мс |
| 3902 | 2 | 100 мс |
| 3951 | 3 | 150 мс |
| 3952 | 4 | 200 мс, затем разблокировка |

Отсюда суть attack4: замеряя время отклика по линии SENSE, PIN снимается посимвольно за `<= 40` попыток вместо `10^4`. `oracle_demo.mjs` считывает эталон из дампа, сравнивает наблюдаемую длительность префикса и флаг разблокировки, возвращает ненулевой код при расхождении; сохранённый прогон — [`oracle_demo_output.txt`](oracle_demo_output.txt). Физический замер и [видео](../oracle-attack.mp4) описаны в [основном отчёте](../README.md)

## Как устроено (кратко)

- `stand.mjs` детерминированно повторяет цикл `Simulator.execute()`: продвигает виртуальные часы (чтобы работал таймер и `sleep_ms`), перематывает через WFE; входные пины энкодера дёргаются `gpio[N].setInputValue`, индикатор читается `gpio[N].outputValue`
- пины мишени: GPIO 29=A, 27=B, 28=SW; таблица "цифра→сегментный пин" читается из флеша по указателю `0x10000df0`

## Ограничения (честно)

- прогон медленный: JS эмулирует ~5 с виртуального времени сейфа за ~100 с реального — это один прогон, не проблема
- нужен реальный bootrom-бинарь (crt0/периферия зовут ROM-функции); он качается скриптом, в репозиторий не кладётся
- USB device-mode в rp2040js без готового MSC-хоста, поэтому стенд доводит атаку до **факта разблокировки** (флаг + подъём USB-стека), а не до монтирования диска; расшифровка тома — офлайн в [attack1](../../attack1/README.md)/[attack3](../../attack3/README.md)
- тайминг-оракул на настоящей прошивке проверяется инструментированием `sleep_ms` через [`oracle_demo.mjs`](oracle_demo.mjs); модель стратегии подбора — в [`../sim/emulator_sim.py`](../sim/emulator_sim.py)
