# Исходный образ и архив задания

[`backup_full.bin`](backup_full.bin) — полный дамп внешней флеш-памяти сейфа; способ получения с платы описан в [attack0](../attack0/README.md). [`your_prize.zip`](your_prize.zip) извлечён из зашифрованного тома этого образа, а не получен из отдельного источника

## Воспроизведение извлечения ZIP

Из корня репозитория:

```sh
python3 artifacts/prepare.py /path/to/backup_full.bin --reference-zip /path/to/your_prize.zip
```

Скрипт вызывает [дешифратор attack1](../attack1/decrypt_storage.py), извлекает архив через `mcopy` (пакет mtools) и проверяет содержимое и CRC средствами Python. Необязательный `--reference-zip` дополнительно проверяет побайтовое совпадение с исходным ZIP. Чтобы не перезаписать опубликованные артефакты, скрипт отказывается работать, пока файлы с целевыми именами уже существуют

Для проверки уже сохранённых файлов без их перезаписи:

```sh
python3 artifacts/prepare.py artifacts/backup_full.bin --verify
```

Этот режим повторно извлекает ZIP во временной папке и сравнивает хэши сохранённых файлов с результатом

## Распаковка вложенных архивов

Внешний ZIP содержит `layers.zip` и `readme.txt`. Каждый вложенный `layer_N.zip` защищён паролем `N`; [`unpack_layers.py`](unpack_layers.py) передаёт очередной архив в `7z`, проверяет имя следующего файла и сохраняет `prize.html` только после успешного прохода всех слоёв

```sh
python3 artifacts/unpack_layers.py artifacts/your_prize.zip /tmp/prize.html
```

На исходном архиве проверен полный проход 1337 слоёв; SHA-256 результата совпал с файлом `prize.html` из материалов задания. Скрипт не перезаписывает существующий файл. Тест двухслойного контрольного архива: `python3 -m unittest discover -s artifacts -p 'test_*.py' -v`
