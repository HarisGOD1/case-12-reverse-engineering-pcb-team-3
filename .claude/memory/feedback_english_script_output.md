description: Сообщения скриптов на английском, а сохранённые протоколы побайтово совпадают с stdout
metadata:
  node_type: memory
  type: feedback

Пользовательские сообщения скриптов и сохранённые протоколы stdout должны быть на английском; каждый `.txt` должен побайтово совпадать с выводом соответствующего запуска

**Why:** Пользователь не хочет смешанных языков и рукописных пояснений внутри протоколов

**How to apply:** После изменения сообщения повторно запускать команду и сравнивать stdout с сохранённым файлом; объяснения помещать в русскоязычный README
