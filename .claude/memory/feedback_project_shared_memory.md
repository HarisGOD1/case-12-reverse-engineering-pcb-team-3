Долговременный контекст этого проекта хранить в `.claude/memory/` внутри репозитория, а не в каталоге памяти harness. Личные заметки, не относящиеся к репозиторию, оставлять вне Git

**Why:** Пользователь уточнил направление переноса памяти и выбрал общий доступ к проектным записям без публикации личных

**How to apply:** Перед сохранением проверять существующие записи; добавлять только решения и сведения, которые нельзя получить из текущих файлов, и не дублировать код, диффы или протоколы
