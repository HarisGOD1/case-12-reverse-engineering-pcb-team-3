Трек Positive Technologies на ЛЦТ 2026 — получить доступ к прошивке кибер-сейфа и описать уязвимости. Эта память общая для команды, лежит в репозитории; приватное и личное сюда не пишем.

## Устройство

Кибер-сейф на **Raspberry Pi RP2040**, bare-metal (Pico SDK + TinyUSB), выставляет флешку наружу как USB Mass Storage. Скрытое хранилище на флеше `0x10100000` (704 КБ) открывается 4-значным PIN, который вводится физически энкодером. Дамп прошивки снят через `picotool save -a backup_full.bin` из BOOTSEL — на RP2040 нет защиты флеша от считывания.

## Главная находка

Хранилище зашифровано самодельной XOR-гаммой (стиль CTR). Ключ гаммы — фиксированные константы прошивки (пул `0x100004ec..0x10000538`), PIN в криптографию не входит. Дешифратор — read10-колбэк `0x10000354`, шифратор записи `0x1000053c`. Хранилище расшифровано оффлайн из дампа: FAT12 → `your_prize.zip` → матрёшка из 1337 запароленных zip (пароль каждого слоя = его номер) → HTML-страница с рикроллом. PIN гейтит только видимость флешки на хосте, не крипту. Аппаратной защиты на RP2040 нет — ни secure boot, ни readout protection, ни OTP под ключи (появились только в RP2350).

## Векторы атаки (отчёты в репозитории)

- `attack1/` — фиксированный ключ шифрования в прошивке (CWE-321): оффлайн-дешифровка хранилища из дампа + PoC `decrypt_storage.py`
- `attack2/` — подмена содержимого / evil-maid (CWE-345): той же известной гаммой шифруется вредонос и пишется в флеш
- `attack3/` — слабость самого шифра (CWE-327): линейная гамма вскрывается known-plaintext

Ориентиры CVSS: вектор 1 — 4.6→6.1, вектор 2 — 6.1→7.8, вектор 3 — 4.6→6.1.
